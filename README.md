# 🔥 送信前の炎上チェッカー

送る前のメールや Slack の文章を貼ると、**相手にどう受け取られるかを生成AI(Claude)が予測する** Next.js アプリです。

## できること

文章と一緒に **送り先**(顧客 / 上司 / 後輩 / 他部署 / 社外パートナー)と **媒体**(メール / Slack・Teams)を選んでチェックします。同じ文章でも、送り先や媒体によって判定と書き直し案が変わります。

- **炎上度の判定**:5段階の🔥と、一言のキャッチコピー。原文の危ない箇所は波線でハイライトされます
- **受け取った人の反応予測**:送り先ごとに用意したキャラクター(4〜5人)から毎回ランダムに3人を選び、返信・心の声・既読スルー確率を予測します。もう一度チェックすると、別の人が反応します
- **危険ワードの指摘**:問題のある言い回しと、その理由・言い換え案
- **書き直し案**:4つのトーンで全文を書き直します。
  - やわらか:クッション言葉を足し、責める感じを消す
  - ビジネス標準:口語・略語をビジネス用語と敬語に置き換え、送り先と媒体に合った書き出し・結びを付ける
  - 簡潔:結論と依頼だけを短く残す
  - 🙇土下座:ネタとして大げさに謝り倒す
- 書き直し案は「コピー」できるほか、「この案で再チェック」でその案のままチェックし直せます
- AI の応答を待っている間は、入力欄・送り先・媒体を操作できません(診断中の条件と画面の選択がずれないようにするため)

## 実行例(本物の AI の出力)

**入力**:「その後の進捗はいかがでしょうか。おせーよ。」/ 送り先:顧客 / 媒体:メール

- **炎上度**:🔥🔥🔥🔥🔥「丁寧語からの急転直下ジェットコースター」
- **診断**:一文目は丁寧なのに、二文目の「おせーよ」で顧客への暴言に化けています。顧客宛てメールでこれが届けば、取引停止や上席へのエスカレーションまであり得る大炎上案件です。
- **反応予測(3人中1人)**:決裁権のある無口な役員
  - 反応:(返信なし。翌週、御社の営業部長宛てに一行だけメールが届く)
  - 心の声:……次の更新はないな。
- **書き直し案(ビジネス標準)**:

  ```
  〇〇様

  いつもお世話になっております。△△の□□でございます。

  先日の件につきまして、その後の進捗状況はいかがでしょうか。
  当初の予定より時間が経過しておりますため、現在の状況と今後の見通しをご教示いただけますでしょうか。

  お忙しいところ恐縮ではございますが、何卒よろしくお願い申し上げます。
  ```

AI の出力は毎回変わります。

## 仕組み

```
ブラウザ(src/app/page.tsx)
  └─ POST /api/check  { message, recipient, channel }
       └─ Route Handler(src/app/api/check/route.ts)
            ├─ ANTHROPIC_API_KEY あり → Anthropic Messages API(structured outputs で JSON を強制)
            └─ ANTHROPIC_API_KEY なし → デモモード(src/lib/mock.ts のルール判定)
                 → 炎上度・反応・危険ワード・書き直し案を同じ JSON 形式で返す
```

| ファイル | 役割 |
|---|---|
| `src/app/page.tsx` | 画面。入力フォームと結果カードの描画 |
| `src/app/api/check/route.ts` | API。入力チェック、AI 呼び出し、エラー処理 |
| `src/lib/schema.ts` | 入力と返却 JSON の形を zod で定義。`client.messages.parse()` + `zodOutputFormat()` で型安全に受け取る |
| `src/lib/prompt.ts` | AI への指示(システムプロンプト)と、反応キャラクターの候補 |
| `src/lib/mock.ts` | デモモードの判定ルールと言い換え表 |

### デモモードについて

API キーが無いときは、AI の代わりに**ルールで簡易判定**します。キーが無くても画面と一通りの動きを確認できます。

- 「まだでしょうか」「リスケ」などの危険ワード(15種)と、「おせーよ」「使えない」「は？」などの乱暴な言い方・スラング(正規表現 8パターン)を検出し、送り先ごとの重みで炎上度を計算します
- 書き直し案は、言い換え表(「すみません→申し訳ございません」など)で置き換えて作ります
- 媒体は、メールでくだけた表現を使った場合に炎上度を上げるのにだけ使っています
- **登録したパターンにしか反応しない**ため、ルールに無い言い回しは見逃します。結果には「(デモ)」と表示されます

## 動かし方

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を記入(省略するとデモモード)
npm run dev
```

http://localhost:3000 を開きます。

- API キーは https://console.anthropic.com/ で発行できます。`.env.local` は git の管理外です
- 本物の AI で動かす場合、1回のチェックに **10〜20秒ほど**かかり、API の利用料金がかかります
- 使うモデルは `.env.local` の `ANTHROPIC_MODEL` で変更できます

## 技術スタック

- Next.js 16(App Router)/ TypeScript / Tailwind CSS
- `@anthropic-ai/sdk`(モデル:`claude-opus-5-5`、effort `low`)
- zod(入力バリデーションと出力スキーマ)

## 開発メモ

Claude Code に指示を出しながら作成しました。最初の実装のあと、実際に触って見つけた問題を指摘して直しています。

- 送り先を変えても炎上度が変わらない → デモモードを送り先別の重み付き判定に変更
- 書き直し案が挨拶を足すだけで、言い換えになっていない → トーンごとの言い換えを実装
- 「まだ。早くしてよ」「おせーよ」を見逃す → 催促・暴言・スラングの検出を追加
- 「この案で再チェック」を押しても何も起きない → 押したらその案でチェックし直すように修正
- 診断中に送り先を変えられてしまう → 診断中は入力を操作できないように変更
